# HowlRex Website — Final

Responsive cinematic static website for the HowlRex YouTube/creator brand.

## Included
- Black / deep-blue / gold visual identity
- Hero, About, Portfolio, Automotive, Video and Contact sections
- Supplied images and web-optimized video files
- YouTube CTAs pointing to https://www.youtube.com/@HowlRex
- Scroll animations and mobile navigation

## Run locally
Use a local server in this folder, for example:

    python -m http.server 8080

Then open http://localhost:8080

## Publish
Upload the entire folder to a static host such as GitHub Pages, Netlify or Vercel.

## Final customization
Replace the Instagram placeholder link in index.html with your official Instagram URL. Add individual YouTube video/Short URLs when you want them featured as separate embeds.
