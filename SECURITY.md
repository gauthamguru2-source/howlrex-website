# HOWLREX Security

The official HowlRex identity is limited to:

- https://howlrex-website.vercel.app/
- https://www.instagram.com/howlrex07/
- https://www.youtube.com/@HowlRex

Do not treat other profiles, websites, accounts, or messages as official HowlRex destinations.

## Repository protection

The `main` branch should be protected so direct unreviewed changes, force-pushes, and branch deletion are blocked. Require pull requests and Code Owner approval for changes.

Never publish GitHub, Vercel, domain, or social-account credentials in the repository.
